# Bulls & Cows

A browser-based number guessing game inspired by the classic Bulls & Cows game.

## How It Works

Guess the secret 4-digit number using the clues from each attempt:

* **Bull** — correct digit, correct position
* **Cow** — correct digit, wrong position

Use logic, eliminate possibilities, and crack the number.

* HTML
* CSS
* JavaScript
